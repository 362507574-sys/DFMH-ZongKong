# DFMH-ZongKong

一个 GitHub 入口安装 DFMH 控制中心、5个组织、15个组织技能、2个公共技能，以及可选的飞书总控和质量发布模块。

## 推荐方式｜把一句话发给Codex

打开一个新的 Codex 对话，把下面这句话原样发送：

> 请安装并初始化这个Codex插件：https://github.com/362507574-sys/DFMH-ZongKong 。采用完整安装，自动完成依赖检查和自检；成功后列出5个组织、15个组织技能、2个公共技能及各自成熟度。

Codex 会自动添加市场源、安装 `dfmh-zongkong@dfmh`、初始化本机运行目录、解压固定版本能力包并执行自检。使用者不需要手工创建文件夹或复制五个组织。

## 安装后怎么使用

- 普通问题：直接对话，不创建项目。
- 正式工作：使用“项目：项目名称＋希望得到的结果”发起，由总控判断主责组织和所需技能。
- 修改成果：在原项目中继续说“修改、补充、调整”，不得重新创建项目。
- 首个项目示例、手动命令备用方式、验收标准和更新方法见 `QUICKSTART.md`。

## 只需要一个组织

五个组织仓库仍可分别下载并作为独立 Codex 项目使用；那种方式不会安装总控，也不会自动获得其他组织。每个组织仓库的 `QUICKSTART.md` 都写明两种方式。

## 隐私

仓库不包含发布者或安装者的飞书凭据、身份、群聊、知识库、客户项目、任务记录和本机路径。飞书默认关闭，必须使用安装者自己的应用信息。

## 边界

安装成功只代表控制入口和能力包结构可用，不会自动改变各组织登记的成熟度和正式任务许可，也不保证不同模型和业务资料产生完全一致的内容。

详见 QUICKSTART.md、PRIVACY.md 与 SECURITY.md。
