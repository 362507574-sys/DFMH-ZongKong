# DFMH-ZongKong

一个GitHub入口安装DFMH控制中心、飞书总控和质量发布模块。

## 推荐安装

把下面这句话发给一台新的Codex：

> 请安装并初始化这个Codex插件：https://github.com/362507574-sys/DFMH-ZongKong 。采用完整安装，自动完成依赖检查和自检。

安装者不需要手工创建文件夹。Codex会添加市场源、安装插件并运行初始化。联网、写入用户目录和飞书授权可能需要安装者确认。

## 隐私

仓库不包含发布者或安装者的飞书凭据、身份、群聊、知识库、客户项目、任务记录和本机路径。飞书默认关闭，必须使用安装者自己的应用信息。

## 边界

本插件提供可复用控制基础，不等于任何发布者的私人运行实例，也不保证不同模型和业务资料产生完全一致的内容。

详见 QUICKSTART.md、PRIVACY.md 与 SECURITY.md。
