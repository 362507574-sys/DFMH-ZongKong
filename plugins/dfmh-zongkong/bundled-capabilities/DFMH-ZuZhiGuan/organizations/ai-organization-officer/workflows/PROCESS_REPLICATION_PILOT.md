# 流程复制正式执行 Workflow

## 定位

本 Workflow 把同企业已批准的人才配置与人才培养资产，转成可执行的流程地图、职责矩阵、SOP、表单审批、知识库、考勤工资框架、员工全周期、合规控制和组织复制包。流程可以由 AI 分析、计算和生成候选；涉及员工权益、资金、合同、账号、生产系统或正式发布的动作仍由获授权使用者决定和执行。

## 固定步骤

### 1. 绑定企业、任务、权限和上游资产

- 读取唯一企业和流程复制任务。
- 固定绑定人才配置、人才培养正式资产的精确版本、候选 SHA-256 和正式资产 SHA-256。
- 不读取其他企业或其他业务项目的动态“最新版本”；跨项目复用必须由控制中心建立固定导入快照。

### 2. 飞书知识前置

- 查询流程、SOP、知识库、工资考勤、员工全周期和组织复制相关资料。
- 保存 `matched`、`no_hit` 或 `degraded` 凭证；无命中或降级继续，但不得虚构内部规则。
- 对命中内容做相关性判断，岗位专业标准仍以上游正式资产和当前企业事实为主。

### 3. 还原真实流程

识别发起人、触发、输入、参与者、步骤、工具表单、审核、输出、等待、错误、例外和真实执行与书面制度差异。不得用“文件已经齐全”代替实际流程验证。

### 4. 设计流程地图与责任矩阵

每一步明确负责人、协作者、审核人、时限、质量标准、输出、异常和升级。不得为了提速删除必要的人力、财务、法务、数据安全或业务审核。

### 5. 形成 SOP、表单与审批

每份 SOP 包含目的、范围、前置条件、材料、步骤、示例、质量标准、常见错误、例外、检查清单、负责人、版本、生效日期和更新条件；表单和审批保留审计轨迹。

### 6. 建设知识库

每条知识记录企业、部门、所有者、来源、受众、权限、版本、生效日期、复核周期、关联与替代关系。过期或其他地区内容不得静默作为当前规则。

### 7. 考勤、工资与员工全周期

- 考勤：分析排班、打卡、请假、加班、调休和异常，AI可计算和提示，是否认定、奖惩或处罚由使用者最终决定。
- 工资：定义输入、公式、校验、制表复核批准分离、员工确认和争议流程；真实任务必须绑定地区、周期和当前政策。AI不发薪、不改工资、不提交银行、税务或社保文件。
- 员工全周期：覆盖招聘、入职、试用、转正、调动、发展与离职，所有高影响人员决定由使用者完成。
- 合同、社保、公积金和劳动制度需要当前官方来源及专业复核；本能力不冒充法律意见。

### 8. 组织复制包

形成复制条件、组织结构、编制岗位、人才标准、招聘、入职培养、日常管理、SOP、表单、知识、工具、质量和启动条件。

### 9. 试点与异常

正式启用前必须覆盖正常链路、权限错误、版本漂移、异常输入、回退和高风险动作阻断，全部硬门禁必须零失败。工资至少完成一次全周期影子计算且无无法解释的人员或金额差异；考勤至少覆盖企业定义的一个完整周期，所有异常均有确认人与证据。不能因赶时间跳过会影响员工权益或资金的验证。

### 10. 使用者决定与正式晋级

- `approve`：保存原话、范围、时间和候选 SHA-256，写入新正式版本。
- `revise`：创建新版本，不覆盖旧版。
- `reject`：保留候选和原因。

批准必须绑定精确候选。使用者批准不能替代法定程序和专业复核。未经明确授权不得向员工发通知、签约、发薪、申报、开通生产权限、修改账号或切换外部系统。

批准后的外部动作通过控制中心正式接口交给明确执行人和独立复核人，绑定幂等键、精确版本、执行前复核、回执和停止条件；非幂等动作失败后不得自动重试。

### 11. 运行复盘

记录流程时间、等待、错误、返工、例外、知识命中、工资考勤差异、使用者反馈和政策变化。变更上游资产、规则或地区后重新验证受影响部分。

## 重试与停止

- 临时知识服务、只读查询、文件并发和可修正字段可以有限重试。
- 同一根因最多三轮；第三轮仍失败时停止并保留证据。
- 外部合同、社保、付款、发薪和生产写入失败时禁止无界自动重试，防止重复提交。
- 跨企业、越权、哈希漂移、过期政策、跳过试点、自动人事决定、未授权外部写入或覆盖正式版本时立即停止。

## 非技术交付顺序

流程诊断 → 流程地图 → 职责矩阵 → SOP → 表单审批 → 知识库 → 考勤工资与员工全周期 → 组织复制包 → 试点结果 → 风险未知 → 使用者待决策事项 → 正式版本与回传包。

## V2全闭环

按任务选择流程与SOP、经验与知识、工资考勤员工运营、新组织复制四种内部模式。执行链为：真实流程还原 → 现状诊断 → 目标流程 → 责任与控制点 → SOP表单检查清单 → 试点 → 调试优化 → 知识库 → 组织复制包 → 运行监控 → 总控回传。

真实工资必须完成无未解释差异的影子核算；真实考勤必须覆盖完整周期并清零未确认异常。发现岗位或培养资产失效时只提交上游变更请求，不静默修改。
