# AI组织官概览

AI组织官是AI数字员工控制中心内部的组织复制系统，负责把经营目标转成组织架构、岗位、人员标准、培养体系、制度、SOP和企业知识资产。

## 三个核心技能

- 人才配置：组织诊断、岗位说明、人才画像、招聘标准、人岗匹配、绩效薪酬和组织调整建议。
- 人才培养：新人培养、岗位训练、能力评估、成长路径、管理者培养和经验传承。
- 流程复制：SOP、表单、审批、知识库、考勤、工资核算、合同社保流程和新组织复制。

## 当前真实状态

三个核心能力均已形成正式Skill和正式企业资产，链路固定为“人才配置 → 人才培养 → 流程复制”，并通过精确版本和SHA-256校验。根控制中心已登记为`operational / acceptsFormalTasks=true`，可以接收正式任务。普通宣传海报与淘宝电商套图仍是根级公共能力。

正式流程为：识别企业与权限 → 知识前置 → 诊断 → 候选 → 质量门禁 → 使用者决策 → 试运行 → 正式企业资产 → 控制中心回传。

V2增加单Skill、连续链和继续执行三种总控调用模式；每次任务保存规划、时间线、证据、质量、调试、决定和回传七类凭证。三个Skill采用条件式依赖，下游只能向总控提交上游变更请求。
