# DFMH-HaiBaoSheJi

## 海报设计技能

面向节日、活动、品牌、产品及社交渠道的专业宣传海报设计与验收流程。

- 公共技能编号：`public.promotional-poster`
- 当前成熟度：`operational`
- 状态说明：正式运行版：具备任务清单、流程门禁、模板、质量检查和异常停止条件。

## 主要能力

1. 节日、活动、品牌、产品及社交渠道宣传海报。
2. 平台画像、品类适配、参考视觉 DNA 与多方向预选。
3. 素材授权、产品真实性、提示词溯源、候选审核与正式晋级。
4. 浏览器连续动作、超时记录、失败重试和下载确认。

## 使用方法

1. 安装 Node.js 20 或更高版本。
2. 阅读根目录 `SKILL.md` 与对应的 `workflows/` 流程。
3. 将每个客户任务放入独立目录；不要把客户图片、隐私、账号凭据或历史输出提交到本仓库。
4. 按 `templates/` 创建任务清单，并通过 `scripts/` 中的流程门禁。
5. 执行 `npm test` 检查文件完整性、登记绑定、本地依赖与敏感信息。

## 仓库内容

- `SKILL.md`：公开分发入口。
- `skills/creating-promotional-posters/SKILL.md`：项目中的权威来源入口。
- `workflows/`：任务流程与停止条件。
- `templates/`：任务、提示词和品类模板。
- `scripts/`：流程门禁、素材准备和连续动作组件。
- `tests/`：契约测试与验收标准。
- `shared/`：生图通道、浏览器动作和产品真实性公共标准。
