# 交付验收清单

## 能力覆盖

1. 需求确认、平台画像、品类适配与视觉方向预选
2. 素材授权、产品真实性、提示词溯源和候选审核
3. 浏览器连续动作、失败停止和正式晋级

## 每项成果必须具备

- [ ] 核心判断明确，不只是罗列资料。
- [ ] 推导逻辑能够从事实或已标注的假设追溯。
- [ ] 事实、来源、推断和信息缺口分开。
- [ ] 方案能够落实为动作、顺序、责任角色和时间安排。
- [ ] 包含可观察的验收指标。
- [ ] 包含风险和停止条件。
- [ ] 未把模拟数据写成真实结果。
- [ ] 未声称已调用本仓库没有的飞书、网页账号、私有知识库或其他组织。

## 最终判断

只有以上项目全部满足，才能把结果提交给使用者验收。
