## 二、需求与确认

- [ ] 已先读取需求者提供的信息，没有重复询问。
- [ ] 第一轮一次性提出全部必要问题。
- [ ] 回答不完整时只补问缺失或冲突部分。
- [ ] 需求者授权补齐后，数字员工完成了专业补全。
- [ ] 补全后的完整设计需求经过需求者确认。
- [ ] 未经确认前没有进入正式制作。
- [ ] 硬性事实与可优化文案已经明确区分。

## 三、任务模式

- [ ] 有原图时完成了真正的版式与视觉重构，而非简单换背景或加滤镜。
- [ ] 无原图时根据确认需求建立了完整视觉方案，没有虚构事实。
- [ ] 任务属于电商套图时已正确分流，没有冒用普通海报流程。

## 四、成品质量

- [ ] 交付的是完整成品海报，不是单独背景或概念图。
- [ ] 主题、用途和受众匹配。
- [ ] 信息层级清晰，核心信息能够快速识别。
- [ ] 品牌名、产品名、日期、价格、地址、规则等硬性信息准确。
- [ ] 中文无错字、乱码和错误数字。
- [ ] Logo 使用真实素材且没有变形。
- [ ] 二维码使用真实素材并可识别。
- [ ] 产品结构、人物五官、手部和肢体自然。
- [ ] 当前生图通道已绑定本任务和本版本；素材授权未被当成其他工具授权。
- [ ] 如有安全拒绝，已记录具体通道和原文，未扩大为所有渠道或全品类禁止。
- [ ] 产品原图路径、SHA-256、身份指纹和可见视角边界已经核对。
- [ ] 候选产品的部件、连接、比例、颜色、材质、Logo、文字和配件与绑定原图一致。
- [ ] 未生成原图不支持的背面、底部、内部或隐藏连接结构。
- [ ] 空间、透视、光线、阴影和材质可信。
- [ ] 留白、装饰、构图和色彩具有成熟商业设计感。
- [ ] 没有未经确认的塑料质感、蓝紫发光、卡片堆叠等典型 AI 痕迹。
- [ ] 已记录提示词框架路径、版本、SHA-256，网页实际提交提示词与归档文件一致。
- [ ] 存在视觉参考时已完成构图、裁切、环境、光线、配色、字体、材质、留白和反面模式的视觉 DNA 拆解。
- [ ] 参考敏感或审美高风险任务已完成三个方向预选，且实际成图使用的是已选择方向。
- [ ] 已分别完成视觉主体阶段与精确排版阶段，没有用一条过载提示词直接生成最终成品。
- [ ] 已逐项对照参考视觉 DNA；候选没有把自然生活方式参考误做成黑金棚拍、金边光、正脸证件式构图或传统大标题模板。
- [ ] 尺寸、比例、清晰度、色彩和格式符合发布或印刷用途。
- [ ] 重要信息没有贴边、遮挡或被裁切。

- [ ] 需求者确认修改结果符合预期。
