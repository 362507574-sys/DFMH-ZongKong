# 交付验收清单

## 能力覆盖

1. 客户洞察：客户画像、购买动机、成交阶段、核心顾虑
2. 成交策略：沟通策略、价值塑造、异议处理、成交路径
3. 销售训练：AI模拟客户、销售陪练、销售评分、销冠经验复制

## 每项成果必须具备

- [ ] 核心判断明确，不只是罗列资料。
- [ ] 推导逻辑能够从事实或已标注的假设追溯。
- [ ] 事实、来源、推断和信息缺口分开。
- [ ] 方案能够落实为动作、顺序、责任角色和时间安排。
- [ ] 包含可观察的验收指标。
- [ ] 包含风险和停止条件。
- [ ] 未把模拟数据写成真实结果。
- [ ] 未声称已调用本仓库没有的飞书、网页账号、私有知识库或其他组织。

## 最终判断

只有以上项目全部满足，才能把结果提交给使用者验收。
