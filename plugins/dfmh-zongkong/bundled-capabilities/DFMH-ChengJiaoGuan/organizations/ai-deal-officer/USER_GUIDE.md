# AI成交官｜用户使用指南

用户只需说明企业、产品、客户场景和期望结果，例如：

- “分析这批咨询客户为什么没有成交。”
- “根据已经确认的客户洞察，设计成交沟通和异议处理。”
- “把这套成交方法做成销售陪练和评分。”

执行助手会自动选择技能、执行飞书知识前置、检查企业隔离和资料授权，并形成候选结果。客户自主决定、价格承诺、合同、收款、退款、客户外联和CRM写入不会自动执行。

当前三个技能均为`pilot`，供用户测试审核；正式任务仍走`fallback_existing`。测试通过并完成真实企业任务、异常路径和端到端复核后，才能评估正式上线。

## AI客户洞察标杆怎么测试

用户只需提供真实企业项目、已授权客户资料以及相关产品和交付事实。系统会自动完成动态规划、证据分类、执行前/中/后调试、客户洞察候选和版本记录。

当前尚无可用于本轮真实验收的授权客户资料，因此真实验收状态保持`waiting_input`。这不会影响公共内核和模拟链路测试，但在真实资料到位、用户审核和结果复盘完成前，AI客户洞察继续保持组织侧`pilot`，不会被描述为正式接单能力。

真实验收记录使用`tests/CUSTOMER_INSIGHT_REAL_TASK_ACCEPTANCE.md`。用户不需要填写技术字段；执行助手会自动记录计划、证据账本、诊断、候选版本与哈希。
