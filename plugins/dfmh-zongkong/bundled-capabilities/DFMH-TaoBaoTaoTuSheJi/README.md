# DFMH-TaoBaoTaoTuSheJi

## 淘宝套图设计技能

面向淘宝主图、详情图与多页面电商套图的策划、产品保真、生成和交付门禁。

- 公共技能编号：`public.taobao-ecommerce-image-set`
- 当前成熟度：`pilot`
- 状态说明：试运行版：具备流程、模板和门禁，但仍需在真实项目中继续验证稳定性，不声明已经达到正式生产成熟度。

## 主要能力

1. 淘宝主图、详情图、服饰、鞋类与童车等品类套图规划。
2. 产品身份指纹、卖点证据、页面职责与系列一致性控制。
3. 逐张生成、逐张验收、套图复核及失败停止条件。
4. 复用海报设计的生图通道、素材上传和产品保真底座。

## 使用方法

1. 安装 Node.js 20 或更高版本。
2. 阅读根目录 `SKILL.md` 与对应的 `workflows/` 流程。
3. 将每个客户任务放入独立目录；不要把客户图片、隐私、账号凭据或历史输出提交到本仓库。
4. 按 `templates/` 创建任务清单，并通过 `scripts/` 中的流程门禁。
5. 执行 `npm test` 检查文件完整性、登记绑定、本地依赖与敏感信息。

## 仓库内容

- `SKILL.md`：公开分发入口。
- `workflows/TAOBAO_ECOMMERCE_IMAGE_SET_PILOT.md`：项目中的权威来源入口。
- `workflows/`：任务流程与停止条件。
- `templates/`：任务、提示词和品类模板。
- `scripts/`：流程门禁、素材准备和连续动作组件。
- `tests/`：契约测试与验收标准。
- `shared/`：生图通道、浏览器动作和产品真实性公共标准。
