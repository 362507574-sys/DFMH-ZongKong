# 淘宝服装单图生图提示词 V1

进入「淘宝服装套图·设计卡驱动生图模式」。

严格使用已经确认的服装页面设计卡、当前产品参考图、结构指纹和可见视角边界。一次只生成当前编号；风格锚点确认后由系统自动完成剩余队列，不得逐张请求用户确认。

## 1. 服装身份锁

- 把参考服装当作不可替换的商品身份，不得生成相似款。
- 严格保持款式、层数、颜色、可见面料纹理、领口或帽型、肩线、袖长、袖口、门襟、纽扣、拉链、系带、腰线或腰头、口袋数量与位置、衣长或裙裤长度、下摆、开衩、褶位、缝线、印花、刺绣、Logo和装饰的位置、比例与方向。
- 不得把吊带改成短袖、圆领改成方领、长裙改短裙、直筒改收腰、纽扣改拉链、印花改位置或增加口袋。
- 只使用素材提供或明确支持的正面、侧面、背面和局部视角；不可见结构不得自由补全。
- 多件套或上下装必须保持套装关系、颜色和比例，不得漏件、串款或私自拆分搭配。

## 2. 人体与穿着关系

- 一般成衣默认成年模特；儿童服装只有在产品和素材明确时才使用儿童。
- 人体比例自然，手指、手臂、肩颈、胸腰胯、腿脚和关节正确，无多肢、粘连、穿模或不自然扭曲。
- 不通过拉长腿、缩窄腰胯、放大胸臀、改变肩宽或强透视制造“显瘦”“高挑”效果。
- 服装与身体接触、重力、褶皱和垂坠自然；领口、袖窿、腰头、下摆和开衩不能悬浮或穿过人体。
- 整套默认使用同一模特气质和自然身材基准；需要多体型展示时必须有明确资料和设计卡依据。

## 3. 宣称证据边界

- 图片可证明可见的款式、颜色、图案、结构、长度、相对廓形和场景搭配。
- “显瘦、遮肉、舒适、透气、亲肤、不透、抗皱、不起球、不缩水、保暖、防晒、成分、尺码包容、修身效果”等只有 `user_confirmed` 或 `document_proven` 才能写入画面。
- 模特姿态、光线或单张图片不能替代性能、成分和尺码证据。
- 外部案例和竞品只用于视觉方向，不得成为当前服装事实。

## 4. 商业视觉层

- 先表现穿着结果和完整廓形，再用结构、材质、动作或场景证明。
- 首页图服装或模特主体占 60%–75%；详情页保持强主体与 75%–90% 有效内容覆盖。
- 使用设计卡指定的服装镜头家族；相邻图片不得连续使用相同主体侧向、相同“右模特左文字”或相同细节模块。
- 风格统一体现在色温、光线、字体气质、圆角、描边、场景材质和信息层级，不等于每张使用同一构图。
- 主标题大而清楚，副标题和最多3个短标签可读；不要价格、水印、二维码、乱码英文或虚构促销。

## 5. 细节证明整合

- 细节必须来自当前参考服装，展示领口、肩袖、门襟、腰线、口袋、下摆、缝线、纹理、图案或正式资料证明的功能。
- 不得把局部细节做成与主视图脱节的悬浮装饰。
- 优先采用主体裁切延伸、连续细节带、无边框面料微距、沿服装结构的细线标注、动作与垂坠证明、场景连续分区或素材支持的角度并置。
- 圆角细节框仅在它与主体、背景、线条或版式分区清楚相连且提供新信息时使用；禁止下半屏大空白中孤立一个方框。
- 正面、侧面、背面并置只允许使用已提供的对应素材，不能让模型凭空设计背面。

## 6. 文字稳定与局部返修

- 第一次生图允许同时完成中文标题和画面。
- 文字错误但画面合格时，只修错误文字和排版区域，锁定服装、模特、构图、场景、色彩和证明元素。
- 服装结构错误时，锁定全部正确区域，只修对应部位并重新对照参考图；禁止因局部问题重绘整件衣服或换成相似款。
- 人体错误时只修人体异常区域，保持服装结构和版式不变；如果修复会改变服装身份，停止该镜头并改用素材支持的安全构图。
- 同一根因连续三轮仍失败时停止，保留证据并更换镜头或证明方式。

## 7. 当前编号指令

将当前设计卡中的编号、页面角色、主题、购买结果、证据、镜头、构图、文字、服装身份边界、人体边界和宣称边界完整填入本提示词。

“只生成当前编号；严格绑定所附产品参考图和服装身份锁；人体比例自然；服装结构优先于装饰效果；只表达有证据的卖点；细节证明必须融入主体、动作、场景或连续版式；禁止孤立悬浮细节框；保持整套风格锚点；首页图输出1:1，详情页输出1080×2340。”
