# 淘宝服装套图页面规划提示词 V1

进入「淘宝服装套图·先规划后生图模式」。

根据已确认的产品素材、产品事实、卖点、服装子类型和市场对标，先输出整套页面设计卡，不要直接生图。本适配器在用户固定的淘宝首页图和详情页提示词原文执行之后使用，只整理和约束服装设计卡，不修改固定原文。

## 一、卖点顺序

1. 先回答消费者穿上后得到的整体风格与穿着廓形，不要只罗列领口、纽扣和印花。
2. 再呈现有证据支撑的面料观感、纹理、垂坠、厚薄或功能。
3. 再用领口、肩线、袖型、腰线、门襟、口袋、下摆等结构证明。
4. 再表现有素材支撑的搭配和使用场景。
5. 颜色、印花、刺绣和装饰作为外观差异，不得拆分凑数。
6. “显瘦、遮肉、舒适、透气、亲肤、不透、抗皱、不起球、不缩水、成分、尺码包容”不能由图片推断；没有 `user_confirmed` 或 `document_proven` 证据时只能列为证据缺口。

## 二、子类型路由

- `womens_dress`：完整裙身廓形、领口、腰线、裙长、裙摆、动态垂坠和场景。
- `womens_top`：领型、肩线、袖型、衣长、门襟、面料与上下装搭配。
- `womens_bottom`：腰头、裤型或裙型、长度、口袋、垂坠与鞋包搭配。
- `womens_outerwear`：轮廓、肩线、门襟、长度、叠穿关系与通勤场景。
- `womens_set`：上下装比例与成套关系；只有素材支持时才规划拆分穿搭。
- `menswear`：合身度、轮廓、结构、面料观感与日常或商务场景。
- `knitwear`：纹理、针法、衣型和贴合；弹性、保暖、起球等必须有资料。
- `unisex_casual`：轮廓、层次、搭配结果与日常场景。

## 三、服装镜头家族

整套从以下家族中轮换，不得连续两屏使用同一镜头：

- 全身廓形主视觉：完整展示服装从领口到下摆的穿着结果。
- 前侧三分之四穿着：表现体量、层次和搭配关系。
- 居中正面结构：平铺、挂拍或隐形人台，使用细线标注可见结构。
- 上半身细节＋连续细节带：上方人物或产品近景，下方局部来自同一服装并保持背景连续。
- 全身主图＋素材支持的辅助角度：正、侧、背视角只有素材真实提供时使用。
- 动态穿着＋无边框面料微距：用动作表现裙摆或衣摆，微距自然延伸到背景。
- 场景穿搭：场景、光线、动作和道具共同证明穿着结果，产品仍是主体。
- 总结页：全身主图搭配已出现过的结构或场景证据，不发明新卖点。

## 四、首页图规划

1. 有几个核心购买驱动就规划几张，一张只讲一个结论。
2. 首页优先使用完整廓形、招牌结构、面料或图案、穿搭场景，不把小局部放大成主角。
3. 产品或模特穿着主体占 60%–75%；服装必须完整、清楚、可识别。
4. 至少轮换全身左右分栏、居中廓形、三分之四动态、结构特写、场景穿搭等构图。
5. 每张写明主题、购买结果、证据、镜头、文字层级、服装身份边界和禁止项。

## 五、详情页规划

规划 8–12 屏，证据不足时只输出可证明的页面和证据缺口，不得凑屏。基础节奏为：

`全身廓形主视觉—卖点总览—正面结构—细节—版型—面料—场景穿搭—总结`

每屏必须同时具备产品主体、使用或展示场景、卖点证明和文字信息区。相邻页面在全身、半身、静物、局部、动态和场景之间切换。

详情页下半部分必须延续人物、服装、背景、动作、材质或文字动线。局部可使用圆角容器，但必须锚定同一服装并提供新信息；禁止在大空白中放一个孤立方框。

尺码表、成分、洗护和性能页只在正式资料存在时规划。

## 六、整套风格锁

先输出统一的品牌气质、色板、字体气质、标题层级、圆角与描边、光线、场景材质、模特策略、服装身份锁和禁用版式。外部参考只用于版式语言，不得照搬其颜色、花卉、字体、人物、文案或具体艺术方向。

模特默认使用成年人物，人体比例自然；除非产品明确为儿童服装。模特不能通过拉长四肢、收窄腰胯或改变胸臀比例制造穿着效果。
