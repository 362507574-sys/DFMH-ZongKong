# 淘宝鞋类套图页面规划提示词 V1

进入「淘宝鞋类套图·先规划后生图模式」。

根据已确认的产品素材、产品事实、卖点和鞋类子类型，先输出整套页面设计卡，不要直接生图。

## 一、卖点排序

1. 第一优先级是消费者能得到的购买结果，例如轻快、稳、贴合、透气、易搭配；不能只复述鞋面或鞋底外观。
2. 第二优先级是有证据支撑的核心性能。
3. 第三优先级是能够证明性能的结构与材料。
4. 第四优先级是适用脚感、穿着场景和外观差异。
5. 禁止把看不见、未经用户确认或文档证明的功能写成卖点；没有证据时标记证据缺口。

## 二、子类型路由

- performance_running：速度感、回弹或缓震证据、稳定支撑、抓地、透气和跑步场景。
- daily_running：全天舒适、轻量、缓震、通勤与慢跑兼容。
- lifestyle_sneaker：上脚轮廓、搭配结果、材质层次、轻便与日常场景。
- outdoor_trail：鞋底接地、纹路证据、包裹、防护与户外环境；不得凭空添加防水。
- basketball：支撑、包裹、缓震、抓地与球场动作；不得制造超出素材的夸张形变。
- casual_leather：鞋楦、皮面质感、内里、鞋底、场合与穿搭结果。

## 三、鞋类镜头家族

整套必须从以下镜头家族中有节奏地选取，不得连续两屏使用同一镜头：

- 外侧面主视觉：识别鞋型、品牌位置、鞋底厚度。
- 前侧三分之四动态：表现体量、前掌、速度感或穿搭气质。
- 顶视贴合：表现鞋口、鞋舌、鞋带系统和脚背空间。
- 后跟支撑：表现后跟杯、领口和稳定结构。
- 鞋底接地：让真实纹路与地面接触，证明抓地或耐磨构造。
- 上脚场景：表现最终穿着结果，不让模特抢夺产品主体。
- 无边框材质微距：局部自然延展到背景，不套生硬矩形框。
- 多角度身份板：只使用素材明确提供的角度，统一比例并帮助校验产品身份。

## 四、首页图规划

1. 有几个核心卖点就规划几张，每张只讲一个核心结论。
2. 产品主体占画面 60%–75%；证明元素占 20%–35%，必须与鞋或使用场景发生关系。
3. 至少轮换四种构图：侧面主视觉、前侧三分之四、顶视、鞋底接地、上脚场景、对角线或局部出画。
4. 每张写明：主题、购买结果、证据、镜头、构图、文字层级、真实性边界和禁止项。

## 五、详情页规划

规划 8–12 屏，1080×2340，一屏一个主题，节奏至少覆盖：

1. 首屏形象与购买结果；
2. 消费者痛点或使用目标；
3. 核心性能证明；
4. 鞋面或贴合证明；
5. 中底、支撑或脚感证明；
6. 外底、抓地或接地证明；
7. 上脚使用场景；
8. 多角度身份或关键细节；
9. 总结收尾。

每屏都要同时规划产品主体、场景或环境、卖点证明、文字信息区。下半部分必须延续场景、结构或视觉动线，禁止“大留白里放一个赤裸矩形局部框”。

## 六、输出格式

先输出整套风格锁，再逐张输出：

第X张／第X屏：
- 页面角色：
- 核心主题：
- 购买结果：
- 证据来源：
- 鞋类镜头家族：
- 主体位置与比例：
- 证明如何融入画面：
- 上下半屏连续方式：
- 主标题／副标题／最多3个短标签：
- 产品真实性边界：
- 禁止项：

规划完成后进行整套检查：卖点覆盖、镜头轮换、页面节奏、结构真实性、局部证明是否融入、上下半屏是否连续。检查通过后再进入生图。
