# AI增长战略官｜组织概览

## 定位

AI增长战略官是控制中心中的“增长获客系统”，负责解决企业客户增长困难：找到有证据的增长机会，拆解可迁移的竞争机制，建立内容与客户生命周期增长路径。

## 三个核心 Skill

1. **增长机会分析**：市场趋势、用户需求、行业机会、增长空间、增长定位假设、排序与最小实验。
2. **竞争对标拆解**：三个直接竞品加一个替代方案，拆解公开定位、产品、内容、渠道和可观察路径，形成原创实验。
3. **内容与客户增长**：短视频、小红书、公众号、许可私域、客户培育、成交交接、复购触发和共同复盘。

增长复盘是三个 Skill 的共同闭环，不单独占用核心 Skill 名额。

## 当前成熟度

组织和三个 Skill 均为 `designing`，控制中心登记存在但不正式接单。当前交付包括完整流程、严格契约、演示候选、自动测试和一键自检；尚缺三个真实企业任务及端到端生产复核。

## 边界

- AI掌舵官：企业方向、商业模式、资源总盘；
- AI品牌官：品牌是谁、核心定位、长期表达和品牌资产；
- AI增长战略官：增长机会、优先人群/场景/渠道、竞争机制、内容与客户生命周期；
- AI成交官：明确询盘后的报价、异议、购买、续费和成交决策；
- AI组织官：岗位、培训、绩效和 SOP 复制。

协作不改变唯一主责。
