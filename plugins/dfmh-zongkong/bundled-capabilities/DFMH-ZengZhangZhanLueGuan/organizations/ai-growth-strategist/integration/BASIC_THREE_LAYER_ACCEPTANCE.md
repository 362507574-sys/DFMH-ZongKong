# AI增长战略官｜三层基础版验收说明

## 1. 本阶段目标

先交付可以使用和验收的基础版，不等待生产级增强全部完成。

## 2. 业务层

完整增长任务固定按以下顺序执行：

1. 增长机会分析：输出 `growth-opportunity-brief`。
2. 竞争对标拆解：读取机会简报，输出 `benchmark-mechanism-map`。
3. 内容与客户增长：读取机会、对标、品牌和成交边界，输出
   `content-customer-growth-plan`。

用户只描述最终目标。基础入口自动选择单技能或完整三技能，不要求用户选择技术路线。

## 3. 安全层

基础版固定保留五项门禁：

1. 企业、项目和任务身份锁定；
2. 结论必须有证据，未知保持未知；
3. AI增长战略官不改品牌、价格、退款和成交规则；
4. 禁止自动群发和主动联系客户；
5. 发布、投放、客户触达、价格、退款、品牌承诺、成交承诺和外部写入全部保持
   `awaiting_approval`。

## 4. 验收层

基础版验收只要求：

- 一个正常场景能够选择并串联三个技能；
- 空目标和不安全项目身份被拒绝；
- 八类外部动作不能绕过审批；
- 现有三个技能的v1兼容和关键拒绝测试继续通过；
- 三技能运行状态和成果可以落盘并在中断后恢复；
- 成果已写但清单未写、清单已写但状态未转的两类中断可确定性恢复；
- 重复原大白话命令必须恢复原运行，不得重建任务；
- 完整、端到端或全链路获客增长表达必须按固定顺序选择三技能；
- 修改上游成果必须生成新版本并自动使下游重新执行；
- 跨组织交接必须固定读取 `artifactId@version` 与 SHA-256；
- 用户验收后成果不可原地覆盖；
- 项目一键自检为零问题。

独立新角色证明、扩展检查点链、全量极端攻击和完整重放转入后续增强阶段。
