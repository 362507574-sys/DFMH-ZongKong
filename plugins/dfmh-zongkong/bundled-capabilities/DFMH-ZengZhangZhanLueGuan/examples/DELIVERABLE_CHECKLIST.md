# 交付验收清单

## 能力覆盖

1. 增长机会分析：市场趋势、用户需求、行业机会、增长空间
2. 竞争对标拆解：竞争对手定位、产品策略、内容打法、获客渠道、成交路径
3. 内容与客户增长：短视频策划、小红书种草、私域运营、客户培育、复购设计

## 每项成果必须具备

- [ ] 核心判断明确，不只是罗列资料。
- [ ] 推导逻辑能够从事实或已标注的假设追溯。
- [ ] 事实、来源、推断和信息缺口分开。
- [ ] 方案能够落实为动作、顺序、责任角色和时间安排。
- [ ] 包含可观察的验收指标。
- [ ] 包含风险和停止条件。
- [ ] 未把模拟数据写成真实结果。
- [ ] 未声称已调用本仓库没有的飞书、网页账号、私有知识库或其他组织。

## 最终判断

只有以上项目全部满足，才能把结果提交给使用者验收。
